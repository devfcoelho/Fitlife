# 💚 FitLife

**FitLife** é uma aplicação web de calculadoras de saúde que ajuda o usuário a monitorar indicadores importantes do corpo de forma simples e rápida.

---

## 📋 Funcionalidades

- **IMC** — Calcula o Índice de Massa Corporal com base no peso e altura, indicando a classificação do resultado.
- **TMB (Taxa Metabólica Basal)** — Calcula o gasto calórico basal diário com base em gênero, peso, altura e idade, utilizando a fórmula de Harris-Benedict.
- **Hidratação** — Monitora a quantidade de água consumida no dia, com meta de 2500ml e barra de progresso visual.

## 🚀 Como Usar

1. Clone o repositório:
```bash
git clone https://github.com/devfcoelho/Fitlife.git
```

2. Abra o arquivo `index.html` no navegador.

3. Escolha uma das ferramentas disponíveis na página inicial e preencha seus dados.
